# Google Play Data Safety Notes

This file is a preparation aid, not legal advice. Answer the Play Console form
based on the exact final binary and Google's current definitions.

## WhereIP-operated collection

WhereIP has no developer-operated backend, account system, advertising SDK, or
analytics SDK. The maintainer does not receive lookup requests or the local
cache.

## Third-party service disclosure

The app sends a direct HTTPS request to an IP information provider so it can
return the public IP and related network data. Google may treat data sent from
the device to a third-party service as collection even when the developer does
not retain it.

The request exposes the device network's public IP address. The response may
contain an approximate location and network identifiers. Review the current
definitions for:

- **Approximate location**
- **Device or other identifiers** / IP address
- collection needed for **App functionality**
- whether processing is **ephemeral**
- whether any provider behavior constitutes **sharing**

Do not declare that data is not collected solely because WhereIP has no
backend. Confirm the answers against the final providers' current policies and
Google Play's current Data Safety guidance.

## Security and deletion

- Data is transmitted using HTTPS.
- No WhereIP account is offered, so account deletion does not apply.
- Cached lookup data and settings are local application data and can be
  removed by clearing app data or uninstalling the app.
- No advertising identifier is requested by WhereIP.

## Permission review

The intended release requests only normal internet/network access generated by
the Expo/React Native runtime. Verify the final Android manifest before every
submission and explain any additional permission before release.
